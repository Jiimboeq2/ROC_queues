# ROC craft queues

OgreCraft spell queues for Rage of Cthurath, by archetype. Each queue is there twice: `<name>.xml` for the old OgreCraft
and `<name>.json` for the new OgreCraft (Ogre's new native bot).

- **New OgreCraft:** copy the `.json` into `C:\Program Files (x86)\InnerSpace\Scripts\OgreSave\EQ2\Craft\queues`.
  It is listed on OgreCraft's **Queues** tab under **Save / load a queue**: click its name, then **Load Queue**.
  With ISXJQB, the Queues tab also has **Find on isxjhub**: every queue on isxjhub.com, by expansion and class.
- **Old OgreCraft:** copy the `.xml` into `C:\Program Files (x86)\InnerSpace\Scripts\EQ2OgreCraft\RecipeQueues`.

More on [isxjhub.com](https://isxjhub.com).
